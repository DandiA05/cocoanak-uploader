Cocoanak Uploader

Cocoanak Uploader is an application designed to simplify and automate video uploads to YouTube.

The application uses Google OAuth 2.0 authentication and YouTube Data API v3 to securely connect authorized YouTube accounts and manage video uploads.

Users retain control over their YouTube accounts and must explicitly authorize access before upload functionality can be used.
